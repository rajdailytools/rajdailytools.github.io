Official Notification Rules

IOB LBO Signature Size & Upload Requirements 2026

Extracted strictly from the official notification, Advt No. HRDD/RECT/02/2026-27, Annexure I, dated 07.08.2026.

RequirementOfficial Requirement
Image FormatJPG / JPEG (per the general document-scanning instructions in Annexure I)
Dimensions140 × 60 pixels (preferred)
File SizeBetween 10KB and 20KB — must not exceed 20KB
BackgroundNot specified in the provided official notification
Signature TypeHandwritten signature on white paper with black ink pen; must NOT be in capital letters
Other InstructionsSignature must match the signature given on the attendance sheet/call letter at the time of examination, failing which the candidate will be disqualified

* Where a requirement is not explicitly stated in the official notification, it is marked "Not specified" rather than assumed.

Signature Kaise Resize Hoti Hai?

Ye tool aapke uploaded signature image ko browser ke Canvas API ke through process karta hai. "Resize for IOB LBO" click karne par tool aapki signature ko 140 × 60 pixels ke canvas ke center mein fit karta hai — bina distort kiye — aur JPEG quality adjust karke file size ko 10KB–20KB range ke jitna kareeb possible le jaata hai.

Official Requirement (Annexure I)

Official notification ke Annexure I ke anusaar, signature scan karte samay white paper par black ink pen se sign karna hai. Preferred dimension 140 x 60 pixels hai aur file size 10KB se 20KB ke beech honi chahiye — 20KB se zyada bilkul nahi. Signature capital letters mein nahi honi chahiye.

  • Dimensions: 140 × 60 pixels (preferred)
  • File Size: 10KB – 20KB (max 20KB)
  • Format: JPG / JPEG
  • Signature attendance sheet/call letter ke signature se match honi chahiye
Key Insight: Background colour ke liye official notification mein signature ke liye alag se koi requirement specify nahi ki gayi hai — is wajah se ye tool by default white background use karta hai lekin aap ise optional rakh sakte hain.

Common Mistakes

❌ Mistake 1 — Wrong Dimensions
Mobile camera se click ki gayi signature aksar 1000+ pixels wide hoti hai, jo 140×60 se bahut zyada hai — application form isse reject kar deta hai.
❌ Mistake 2 — File Size Too Large
High-resolution scan ki file size 100KB+ ho sakti hai — jabki official limit sirf 20KB hai.
✅ Correct Approach
Signature ko 140×60 px par resize karke, JPEG quality adjust karke 10-20KB range mein le aayein — is tool se ek click mein ho jayega.
✅ Verify Before Upload
Download karne ke baad, preview mein final width, height aur file size zaroor check kar lein.
Important: Attendance sheet ya call letter par sign karte samay wahi signature style use karein jo aapne application form mein upload ki thi — mismatch hone par candidature disqualify ho sakti hai, jaisa official notification mein bataya gaya hai.
