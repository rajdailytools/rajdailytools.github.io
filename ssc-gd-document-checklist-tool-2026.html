SSC GD Documents — Complete Guide 2026

SSC GD Document Verification Mein Rejection Se Kaise Bacha Jaye?

SSC GD document verification stage bahut candidates ke liye surprise hoti hai — specially wo jo pehli baar apply karte hain. Written exam aur PET/PST clear karne ke baad document verification mein thodi si gadbadi bhi selection ko khatam kar sakti hai. Is tool ka use karo — stage-by-stage documents prepare karo aur last-minute tension avoid karo.

Most Common Rejection Reason: OBC Non-Creamy Layer certificate ki validity expire ho jaana sabse common reason hai rejection ka. NCL certificate generally 3 years valid hoti hai — verification se pehle date check karo. Agar expire ho gayi hai toh fresh certificate banwao taluka/tehsil office se.

SSC GD Admit Card — Sahi Format Mein Kaise Print Karein?

CBT admit card print karte waqt ye ensure karo:

  • Photo clearly visible ho — blurred ya dark nahi
  • Name, roll number, exam center sab clearly readable ho
  • A4 size paper mein print karo — resize mat karo
  • 2-3 extra copies hamesha rakho — original kharaab ho sakti hai
  • Photo same ho jo application mein upload ki thi — mismatch rejection ka reason ho sakta hai

Category Certificates — Validity aur Format

Category certificates sabse critical documents hain reserved candidates ke liye:

  • OBC NCL: Non-Creamy Layer certificate — generally 3 years valid. Central government format mein hona chahiye — state format sometimes accept nahi hota. Verification date se 6 months fresh hona better hai.
  • SC/ST: Permanent nature ki hoti hai generally — lekin prescribed government format mandatory hai. District Magistrate / DC / SDM se issued honi chahiye.
  • EWS: Every financial year ke liye fresh certificate required hoti hai — April mein naya banta hai. Previous year ka certificate usually invalid.
  • Ex-Servicemen: Discharge book original + certificate of service required. Dependent candidates ke liye extra documentation hoti hai.

NCC Certificate Ka SSC GD Mein Faida

NCC certificate holders ko SSC GD final merit mein bonus marks milte hain — directly merit mein add hote hain. NCC 'A' = +2, 'B' = +3, 'C' = +5. Ye certificate document verification par submit karni hoti hai — certificate number aur issue authority clearly mention hona chahiye. Original certificate along with attested copy carry karo.

Document Verification Ke Liye Smart Preparation Tips

  • Ek dedicated folder banao — harr document separate plastic sleeve mein rakho
  • Original + 3 attested photocopies of every document hamesha rakho
  • Documents ka digital scan rakhna — pen drive ya Google Drive mein backup
  • Name spelling check karo — sab documents mein same spelling honi chahiye (10th, 12th, category certificate, aadhar sab match karein)
  • Date of birth sab documents mein same honi chahiye — koi discrepancy nahi
  • Verification se 1 week pehle sab documents ek baar review karo — is tool se cross-check karo
Pro Tip: Document verification mein carry karo — original documents + 3 sets attested photocopies + 6-8 recent passport size photos + pen + notepad. Ek baar is tool se sab check karo, phir confidently verification pe jao. Missing document pe verification ki date miss ho sakti hai.
50 Frequently Asked Questions
1. SSC GD Document Checklist Tool kya hai?+
SSC GD Document Checklist Tool ek free interactive online tool hai jo candidates ko gender, category aur recruitment stage ke hisaab se personalized document list provide karta hai. Har document tick karo — progress track hota hai. CBT exam se lekar final joining tak sab stage ke documents covered hain. Print aur save option bhi available hai.
2. SSC GD ke liye kaunse documents required hain?+
SSC GD ke liye basic documents: Admit card, valid photo ID (Aadhar/PAN/Voter), 10th certificate + marksheet, 12th certificate + marksheet, passport size photos (6-8 copies), category certificate (if reserved), domicile certificate (if required), NCC certificate (if applicable). Stage ke hisaab se additional documents bhi hote hain — is tool mein stage select karo full list ke liye.
3. Kya Aadhar card SSC GD mein mandatory hai?+
Aadhar card SSC GD mein generally accepted ID proof hai — highly recommended. Lekin sirf Aadhar compulsory nahi — PAN card, Voter ID, Passport, ya Driving License bhi valid ID proof hain. Jo ID proof online application mein upload ki hai, usi ka original exam pe carry karna recommended hai. Aadhar-based biometric verification bhi kuch stages mein hoti hai.
4. SSC GD mein educational documents kaunse chahiye?+
SSC GD educational documents: (1) 10th board certificate — DOB proof ke liye. (2) 10th marksheet. (3) 12th board certificate — qualification proof ke liye. (4) 12th marksheet. Sab recognized board se hone chahiye (CBSE, State Board, Open Board). Original + attested photocopies dono carry karo. Appearing candidates ko baad mein result certificate submit karna hota hai.
5. Kya SSC GD mein domicile certificate zaroori hai?+
Domicile certificate SSC GD mein kuch cases mein required hoti hai — especially reserved category candidates ke liye ya state-specific quota ke liye. General category candidates ke liye generally mandatory nahi. Lekin carry karna better hai — verification mein maang sakta hai. State government se issued permanent residence certificate valid hoti hai.
6. SSC GD PET/PST ke liye kaunse documents chahiye?+
PET/PST ke liye: PET call letter / admit card (original), CBT exam admit card (original), valid photo ID (original), passport size photos (2-4 copies), category certificate (reserved candidates), aur koi bhi supporting documents jo call letter mein mention ho. Is tool mein PET/PST stage select karo — complete personalized list milegi aapki category ke hisaab se.
7. SSC GD female candidates ke liye alag documents hote hain?+
Basic document requirements female aur male candidates ke liye mostly similar hain. Female candidates ke liye koi completely alag mandatory document nahi hota. Lekin female candidates ko note karna chahiye: (1) Chest measurement required nahi — related document nahi chahiye. (2) Running distance alag hai — ye document related nahi lekin preparation different. Is tool mein gender = Female select karo — any female-specific notes automatically show honge.
8. SSC GD ke liye caste certificate kaunsa valid hoga?+
SC/ST ke liye: State government prescribed format mein District Magistrate / Deputy Commissioner / SDM se issued. SC/ST permanent certificate generally valid rehti hai — lekin fresh verify karo. OBC ke liye: Non-Creamy Layer certificate — central government format mein, within 3 years validity. EWS ke liye: Current financial year ka income aur asset certificate — annually renew karna hota hai. Template SSC website pe available hoti hai.
9. Documents missing hone par SSC GD mein kya hota hai?+
Document verification mein koi mandatory document missing ho toh candidate ko rejection ya provisional rejection face karna pad sakta hai. Kuch stages mein short date extension milti hai — lekin guaranteed nahi. Isliye advance mein sab documents ready karna zaroori hai. Is tool se checklist generate karo aur verification se 1 week pehle sab check karo. Missing document ka pata pehle chale toh arrange karne ka time milta hai.
10. Kya photocopies SSC GD verification mein acceptable hain?+
Original documents mandatory hain verification ke liye — photocopies supplementary ke roop mein carry karo. Generally self-attested photocopies mangi jaati hain — kuch stages mein gazetted officer se attested copies bhi chahiye hoti hain. Minimum 3 sets of photocopies of every document carry karo. Original dikhane ke baad photocopy jama karna hota hai — original return ho jaata hai usually.
11. SSC GD mein passport size photo ka background kya hona chahiye?+
SSC GD ke liye passport size photos generally white background ke saath required hoti hain. Photo recent honi chahiye — glasses nahi pehnna chahiye generally, smile natural ho. Official SSC notification mein exact photo specifications diye hote hain — unhe follow karo. Minimum 6-8 photos carry karo — different stages mein maange jaate hain. Studio se clear high-quality photos print karwao.
12. NCC certificate SSC GD mein kab submit karna hota hai?+
NCC certificate document verification stage mein submit karna hota hai. Online application mein bhi NCC information fill karna hota hai. Original NCC certificate + attested photocopy carry karo. NCC 'A' = +2, 'B' = +3, 'C' = +5 marks final merit mein. Ye bonus significant hai especially borderline candidates ke liye. NCC certificate government prescribed format mein honi chahiye — NCC directorate se issued.
13. Kya SSC GD application mein documents upload karne hote hain?+
Haan — SSC GD online application mein kuch documents upload karne hote hain: (1) Passport size photo (JPEG, specific size), (2) Signature (JPEG, specific size). SSC notification mein exact file size limits diye hote hain — ensure karo limits ke andar ho. Blurred ya oversized uploads application reject ho sakti hai. Original documents baad mein physical verification pe chahiye hote hain.
14. OBC NCL certificate kitni purani chalti hai SSC GD mein?+
OBC Non-Creamy Layer certificate generally 3 years valid manee jaati hai — lekin SSC GD verification mein usually 1 year ya current year ki fresh certificate prefer ki jaati hai. Safe rehne ke liye document verification se 6 months purani certificate nahi honi chahiye. Central government prescribed format mein honi chahiye — state format sometimes rejected hoti hai. Renewal ke liye tehsil office se fresh certificate banwao.
15. Documents mein spelling mistake ho toh kya karein SSC GD mein?+
Documents mein spelling mismatch ek serious problem hai — specifically name spelling different hone par verification mein issue hoti hai. SSC GD application correction window ke dauran name corrections possible hain — immediately correct karo agar notice hue. Certificate correction ke liye school/board se affidavit process karo. Verification mein affidavit plus correction proof carry karo. Sab documents mein name exact same spelling mein hona best practice hai.
16. EWS certificate SSC GD ke liye kaise banwaye?+
EWS (Economically Weaker Section) certificate SDM/Tehsildar/District Magistrate se banwai jaati hai. Family income ₹8 lakh annual se kam honi chahiye + property criteria meet karna hoga. Current financial year ka certificate chahiye — last year ka generally invalid. Application form + income proof + land records + Aadhar carry karo. Process usually 15-30 days leta hai — advance mein apply karo. SSC prescribed format follow karo — online download karo SSC website se.
17. SSC GD mein kya DigiLocker documents accept hote hain?+
DigiLocker documents kuch government processes mein accepted hote hain. Lekin SSC GD physical verification stages mein generally original documents preferred hote hain. Official call letter mein specifically mention hoga agar DigiLocker accepted hai. Safe practice ye hai ki original physical documents hamesha carry karo — digitally save rakhna backup ke liye useful hai lekin primary verification mein original preferred hota hai.
18. SSC GD document verification kab hoti hai?+
SSC GD document verification PET/PST aur Medical examination ke baad hoti hai. Generally stages hain: CBT → PET/PST → Medical Exam → Document Verification → Final Merit List → Joining. Document verification physical mode mein designated centers pe hoti hai. Call letter mein date, time aur location specified hota hai. Is checklist tool se sab documents advance mein ready karo.
19. SSC GD joining ke liye kaunse documents chahiye?+
SSC GD final joining documents: (1) Appointment/joining letter, (2) All original verified documents, (3) Medical fitness certificate (government hospital), (4) Character certificate (local SDM se), (5) Bank account details (salary account), (6) Passport size photos (fresh set), (7) Aadhar card (for HRMS registration), (8) PAN card (for salary processing), (9) Previous employer's NOC (if applicable). Joining letter mein specific list bhi diya hota hai.

21. SSC GD thumb impression kab deni hoti hai?+
SSC GD mein biometric verification (thumb impression) generally PET/PST ya Document Verification stage mein hoti hai. Ink-based ya digital biometric as per center facility. Thumb impression clear hona chahiye — mehendi ya cuts avoid karo verification se pehle. Koi specific document is ke liye nahi hota — ye on-spot process hai. Hath saaf rakhna aur moisturizer nahi lagana better hota hai clear impression ke liye.
22. SSC GD mein birth certificate zaroori hai?+
Dedicated birth certificate generally mandatory nahi hoti SSC GD mein. 10th board certificate DOB proof ke roop mein accepted hoti hai — ye most reliable DOB document hai. Agar 10th mein DOB clearly mentioned hai toh separate birth certificate nahi chahiye. Kuch cases mein (like name mismatch) affidavit + birth certificate dual proof ke roop mein helpful ho sakti hai. 10th certificate hamesha primary DOB proof carry karo.
23. Kya SSC GD admit card har stage mein chahiye?+
Haan — SSC GD admit card har stage mein mandatory document hai. CBT ka admit card PET/PST mein bhi maanga ja sakta hai. Har stage ka alag call letter/admit card download karna hota hai — SSC website se. Sab stages ke admit cards ek folder mein safe rakhna. Old admit cards delete mat karo — next stage mein required ho sakte hain. Always print karo — digital admission generally accepted nahi hoti physical stages mein.
24. SSC GD verification mein damaged documents se kya hoga?+
Torn, damaged ya unreadable documents verification mein reject ho sakte hain. Agar certificate damaged hai toh: (1) School/Board se duplicate certificate apply karo immediately. (2) SDM se affidavit banwao ki original damaged ho gayi. (3) Board website se verified digital copy download karo. Prevention ke liye sab certificates laminated folder mein rakhna best practice hai. Verification se 1 month pehle sab documents physically check karo.
25. SSC GD mein character certificate kaise aur kahan se banwaye?+
Character certificate SSC GD final joining ke liye required hoti hai — document verification mein bhi maang sakti hai. Generally local SDM (Sub Divisional Magistrate) ya Executive Magistrate se banwai jaati hai. Procedure: Local police verification → SDM office se certificate issue. Process 15-30 days leta hai generally. Joining date se pehle arrange karo — joining letter mein specific instructions bhi diye hote hain. Fresh certificate preferred — 6 months se purani avoid karo.
