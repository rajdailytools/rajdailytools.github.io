IOB LBO Photo Resizing Complete Guide 2026-27

Photo requirements, resizing logic aur common mistakes — sab kuch official notification ke hisaab se.

Photo Kyun Reject Ho Jaati Hai?

Zyaadatar candidates ki photo isliye reject hoti hai kyunki modern phone/DSLR cameras jo images khinchte hain, unki pixel dimensions aur file size official requirement se kaafi zyada hoti hain. IOB LBO 2026-27 notification ke anusaar, photo 200 × 230 pixels aur 20 KB se 50 KB ke beech honi chahiye — jabki ek normal phone photo aksar 3000×4000 pixels aur 3-5 MB tak ki hoti hai.

  • Preferred pixel dimensions: 200 × 230 px
  • Physical print size: 4.5cm × 3.5cm
  • File size range: 20 KB – 50 KB
  • Format: JPG / JPEG only
  • Background: light-coloured, preferably white

Ye Tool Kaise Kaam Karta Hai?

Ye Photo Resizer aapki uploaded photo ko official 200 × 230 pixel canvas mein fit karta hai — ya to Crop to Fill mode se (photo ko bina distort kiye zoom/crop karke) ya Fit with Background mode se (poori photo dikha kar background se fill karke). Uske baad tool JPEG quality ko automatically adjust karta hai taaki final file size official 20-50 KB range ke jitna kareeb ho sake.

Key Insight: "Crop to Fill" gives a tighter passport-style frame but trims the edges of the photo; "Fit with Background" keeps the entire photo visible by adding a light background border. Choose based on how your original photo is framed.

Custom Resize — Kab Use Karein?

Agar aapko koi specific application (IOB LBO ke alawa) ke liye alag dimensions chahiye, to Custom Resize mode use karein. Yahan aap apni width aur height khud enter kar sakte hain, aspect ratio lock kar sakte hain, aur apni target file size bhi set kar sakte hain.

Important: Browser-side JPEG compression cannot guarantee an exact file size — the tool searches for the closest achievable quality within your target range and always shows the actual final file size, never a false "success" message.
